# Frontend

React + Vite 기반 웹 프론트엔드입니다.

## 역할

- 사용자 로그인/회원가입 화면
- 사용자 프로필 입력 화면
- 정책 추천 결과 화면
- 자격 요건 확인 화면
- 제출 서류 관리 화면
- 일정 및 알림 화면
- 기대 효과 리포트 화면

## Tech Stack

- React
- Vite
- JavaScript 또는 TypeScript
- CSS
- Figma

## 주요 화면

- 로그인
- 회원가입
- 마이페이지
- 프로필 등록
- 정책 검색
- 정책 상세
- 서류 관리
- 일정 관리
- 혜택 분석 리포트
